¿Por qué esta tabla se puede llamar genérica? ¿Qué tendría que cambiar para mostrar alumnos en lugar de productos?
Se puede llamar generica porque no esta hecha solamente para productos ya que recibe las columnas y las filas desde afuera asi que puede mostrar distintos tipos de informacion.
Para mostrar alumnos solo tendria que cambiar los datos y las columnas que se le mandan por ejemplo nombre, matricula y carrera

Contrato del componente contador-cantidad
El componente recibe el valor actual el minimo y el maximo y este avisa cuando la cantidad cambia por medio de un evento internamente guarda el valor actual y controla cuando 
se pueden usar los botones de mas y menos
